このページは GTM コンテナ GTM-KXV4CBBD を読み込みます。別のコンテナで試すときは、gtm.html の GTM_ID と noscript の id を書き換えます。

読み込み中…

広告ブロッカーなどで GTM が止められていても、ボタンを押すと右の dataLayer に何が積まれるかは確認できます。

方式AdataLayer.push

ボタンのクリック処理で、意味のある名前のイベントを dataLayer に積みます。GTM 側は「カスタムイベント」トリガーで受け取ります。 

// 資料請求 / 無料で始める
dataLayer.push({ event: "cta_click", cta_name: "資料請求", cta_position: "hero" });

// 会員登録: API が成功した「後」に送る（押しただけでは送らない）
await api.signUp();
dataLayer.push({ event: "sign_up", method: "email" });

// カート追加: 推奨イベントの形。前の ecommerce をリセットしてから push
dataLayer.push({ ecommerce: null });
dataLayer.push({
  event: "add_to_cart",
  ecommerce: { currency: "JPY", value: 8000,
    items: [{ item_id: "plan_pro", item_name: "プロプラン", price: 8000, quantity: 1 }] },
});

方式Bクラス名・data属性で拾う

下のボタンとリンクには onclick も addEventListener もありません。GTM の「クリック」トリガーが .js-track-click クラスや data-track-name 属性を見て拾います。

GTM ヘルプ（外部リンク） 
<button class="js-track-click" data-track-name="pricing_pro">
  <span class="icon">▶</span> プロプランを見る
</button>
class="js-track-click"

オンにすると js-track-click が btn-cta-v2 に変わります（data属性は残ります）。 クラス名で判定するトリガーは止まり、data属性で判定するトリガーは動き続けることを確かめてください。

発展フォーム送信と要素の表示

「フォームの送信」トリガーと「要素の表示」トリガーの練習用です。どちらもページ側に計測コードはありません。

送信はページ内で止めています（preventDefault）。GTM のフォームトリガーは「妥当性をチェック」をオフにしてください。
