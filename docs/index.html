3つの出口の違い

出口見えるもの鮮度向いている用途
GA4 の画面集計済みのレポート。登録したディメンションだけ使えるリアルタイムは数秒、通常レポートは最大24〜48時間日々の確認、マーケ担当との共有

GitHub Pages での公開

GitHub リポジトリに HTML を置き、SettingsPagesDeploy from a branch で main ブランチの / (root) を選ぶと、https://ユーザー名.github.io/リポジトリ名/ で公開されます。push するたびに自動で再デプロイされます。docs/ 配下も同じ仕組みで …/docs/ として公開されます。

ローカルで確認するときは、リポジトリ直下で簡易サーバーを立てます。file:// で直接開くと一部のAPIやGoogleログインが動きません。

python3 -m http.server 8000
# http://localhost:8000/ と http://localhost:8000/docs/ を開く

用語集

イベント
GA4 のデータの最小単位。「ページを見た」「ボタンを押した」など。名前（event_name）とパラメータを持つ。
イベントパラメータ
イベントに付ける追加情報。button_name: "資料ダウンロード" のようなキーと値。
ユーザープロパティ
ユーザーに付ける属性。一度セットすると以降のイベントすべてに付く。例: plan: "pro"。
カスタムディメンション
送ったパラメータやユーザープロパティを、GA4の画面で使える「ディメンション」として登録したもの。
スコープ
値がどの単位にかかるか。イベント・ユーザー・アイテムなど。
測定ID
G- で始まるID。Webデータストリームごとに1つ。送信先を決める。
user_pseudo_id
GA4 が Cookie（_ga）で振るブラウザ単位のID。BigQuery の列名。
user_id
自社のログインIDなど、自分で送るユーザー識別子。端末をまたいで同じ人をまとめられる。
dataLayer
ページ内の JavaScript 配列。計測したい出来事をここに積み、gtag.js や GTM が読み取って送信する。
GTM コンテナ
GTM- で始まるID。タグ・トリガー・変数の設定一式を入れる箱。
タグ / トリガー / 変数
GTM の3要素。「何を送るか」「いつ送るか」「何の値を使うか」。
データセット
BigQuery でテーブルをまとめる単位。プロジェクト.データセット.テーブル で参照する。
UNNEST
BigQuery で配列を行に展開する関数。GA4 の event_params を取り出すのに必須。
