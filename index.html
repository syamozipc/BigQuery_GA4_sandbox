GA4・GTM・BigQuery サンドボックス

GA4 にデータを送り、届いたデータを集計して見て、その仕組みを学ぶための練習用サイトです。

データを送るページでボタンを押す → GA4 に届く → データを見るページで集計を確かめる。仕組みは学ぶのガイドで説明しています。

データを送るログイン不要

ボタンを押すと、GA4 にイベントが送られます。

テストサイト（gtag.js） gtag.js を直書きして送ります。仮ユーザーを切り替えて user_id も送れます。01・02章 GTM 練習ページ GTM 経由で送ります。dataLayer の中身をその場で見られます。03・04章

データを見る要ログイン

BigQuery と GA4 を読むので、閲覧権限のある Google アカウントが必要です。

分析 「リアルタイム」タブは GA4 Data API で過去30分、「過去の推移」タブは BigQuery で日別に集計します。05〜07章

ログインは分析ページで行います。ページを開いている間だけ有効で、移動や再読み込みをすると消えます。
